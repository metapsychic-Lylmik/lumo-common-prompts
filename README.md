# lumo-common-prompts
Lumo Common Prompts   One-click access to 26 reusable prompts for writing, analysis, research, coding, and learning. Adds a 'Common Prompts' button to Lumo so you can stop retyping the same instructions. Matches Lumo's dark theme, survives page reloads, and runs entirely in your browser. Zero external dependencies, nothing leaves your computer.
